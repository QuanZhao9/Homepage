# Quan Zhao — Academic Homepage

A modern, responsive academic homepage for Quan Zhao, Research Professor in the Department of Mathematics at the University of Science and Technology of China.

## Preview locally

Run a static server from this directory:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish with GitHub Pages

The site has no build step. Copy these files to the root of the GitHub Pages repository and publish the repository's default branch from `/ (root)` in **Settings → Pages**.

## Main files

- `index.html` — content and page structure
- `styles.css` — visual design and responsive layout
- `publications.js` — publication records used by the searchable archive
- `script.js` — navigation, research modules, publication filters, and interactions
- `assets/quan-zhao.png` — profile image

GoatCounter analytics is loaded only on the production hostname `quanzhao9.github.io`, so local previews are not counted.
