# Research visualization movies

Place publication-ready movie files in this directory. Prefer web-friendly MP4 (H.264) and keep a descriptive filename, for example:

- `surface-diffusion-axisymmetric.mp4`
- `moving-contact-line-3d.mp4`
- `solid-state-dewetting-curved-substrate.mp4`

Each movie module should include a title, a short explanation, and an optional related-publication link.
